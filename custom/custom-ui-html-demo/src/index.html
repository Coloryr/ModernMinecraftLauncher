这个示例演示了什么

window.mml

启动器注入的桥接对象：拉实例、启动游戏、订阅启动阶段、切换主题。

iframe 沙箱

整页跑在 sandbox iframe 里，没有 allow-same-origin，拿不到启动器页面的 DOM。

零依赖

没有 npm 依赖，也没有打包器；改完 src 里的文件直接压 zip 就能导入。
