M²L 自定义 CSS 示例

这份 CSS 的目标不是这个页面，而是启动器本身。它演示三件事：

  1. 改主题变量（--accent / --bg / --border …），所有窗口一起变；
  2. 用选择器只改某类控件（按钮 / 输入框 / 侧栏 / 标题栏），不碰别的；
  3. 用 ::after 这类选择器做局部装饰。

预览

先起启动器前端（mml-vue，端口 1420），然后打开：

http://localhost:1420/?window=main&customCss=http://127.0.0.1:1521/custom.css

或者把本文件的 CSS 粘进「设置 → 界面 → 自定义界面 → 自定义 CSS」。
