# 更新日志

本文件按版本记录可见变化；安装包与校验和见
[GitHub Releases](https://github.com/Coloryr/ModernMinecraftLauncher/releases)。

0.1.x 都是预发布版，标签带 `-pre` 后缀；界面上的「测试版 / 预发布版」徽章只表示构建通道。

## 0.1.13

### 新增

- 添加实例后自动补全文件：新建、导入文件夹 / 压缩包 / 网址、安装整合包、导入在线服务器包与
  `.minecraft` 成功后，立刻检查缺的版本 json、核心、运行库与资源文件，缺什么就挂到后台下载，
  不用等第一次点启动。下载任务照常出现在下载管理窗口与标题栏的下载指示器里。
- 补全完成前，主窗口的启动按钮显示「检查文件中」或「下载文件中」并带进度条；
  点它是取消补全，下完或取消后回到「启动游戏」。补全期间该实例不能删除 / 改名；
  设置里关掉「自动下载」时不自动补全。
- 实例设置支持选渲染器：游戏内语言右边多了「渲染器」下拉，可选自动 / OpenGL / Vulkan。
  选中的值写进实例 `options.txt` 的 `preferredGraphicsBackend`，下次启动游戏生效。
  这个选项是 26.2 起游戏才提供的，更早的版本不显示这个下拉。
- 日志窗口标题栏多了「打开日志所在文件夹」按钮：选中崩溃报告或历史日志时打开该文件所在目录，
  停在运行日志时打开实例的 logs 目录。
- 主窗口标题栏多了手柄入口：检测到手柄时才出现，点开可以选哪台手柄、用哪份配置、开关游戏内手柄，
  底部的「手柄设置」直接跳到设置窗口的手柄页；手柄拔掉后入口随之收起。
  手柄设置页也从「只有源码构建能进」改成正式版与预发布版都能进。
- 手柄的按钮绑定可以按模式分开：鼠标模式（未抓取鼠标，翻背包 / 开菜单时）与游戏内模式各用一套，
  默认分开、可以手动关掉。配置项是 `SeparateCursor` 与 `CursorButtons`；老配置读进来两套内容相同，
  升级前后的输入行为一致。
- 开着游戏内手柄、但这个实例没有注入 ColorASM 时，启动前会先问一句要不要开启（不开启照样启动）；
  设置里原先那句「需要装好并启用 coloryrasm」的提示由这个弹窗取代。

### 改进

- 资源收藏窗口标题栏的两个入口换成「原图标 + 右下角加号」：整合包与资源各自的图标不动，
  右下角叠一个小加号读作「添加」；收藏为空时仍是占位框里的两个文字按钮。
- 确认类弹窗的按钮统一成「取消 / 确定」：资源收藏的添加分组、删除分组、删除收藏、
  清空分组、移动到分组，以及添加实例的「实例名称冲突」与「是否继续添加」，不再出现「是 / 否」；
  中英两套文案同步删掉这两条。
- 资源收藏的空分组提示去掉白底面板，只剩一行居中提示；搜索没命中的提示同一套，
  玻璃主题的白名单里也去掉了这个类。
- 添加整合包与添加资源两个窗口的下载源页签统一成 CurseForge 在左、Modrinth 在右 ——
  以前按后端返回的顺序排（Modrinth 在前）；没选过时默认 CurseForge，选过的源记在
  `gui_config.json`，下次打开还是那一个。切到「存档」类型时源会被强制成 CurseForge，
  这个强制值不再写成偏好，离开存档类型会回到上次选的源。
- 实例设置里的「日志编码」与「日志窗口 / 自动打开」开关排到同一行，不再各占一行；
  版本没有渲染器选项时日志编码另起一行，不会被补到语言那一行的右侧。
- 实例图标的方块入口不再弹「选择方块图标」小窗：点它直接打开方块列表窗口，在窗口里右键
  方块选「设为实例图标」，与窗口里原有的设图标流程合成一条；那个小窗与它的文案一并删掉。
- 账户被其它实例占用时的启动弹窗改成两个单选：继续启动，或选另一个账户再启动 ——
  选中后者时右侧的账户下拉才可选，里面列出当前账户之外的账户（只有一个账户时不可选）；
  「继续检测账户占用」开关保留，关掉后不再提示。
- 手柄页顶部那行配置（配置下拉、保存、删除、新建）往下滚时吸在内容区顶部，改别的映射不用滚回顶上；
  行尾的「未保存」改成常驻占位，出现时不再把整排按钮挤到下一行。
- 「选择键盘 / 鼠标动作」弹窗里的鼠标与滚轮按钮挪到键盘下方横排，右侧只留方向键，弹窗不再被那一列撑高。
- 手柄的内置默认映射换成一套调好的：A 左键、B 右键、Y 空格（跳）、X 潜行，LT / RT 左右键、
  LB / RB 滚轮，十字键上 / 下 / 右为 Q / F3 / F，Start 是 E、Select 是 Esc；
  鼠标模式单独一套（十字键上 / 下连发滚轮、A 左键、B Esc、LB 潜行）；摇杆速度 1200 / 1500。
  只影响新装或配置目录为空时的默认配置，已经存过 `gamepad/default.json` 的实例如旧；
  「启用游戏内手柄」仍默认关。

### 修复

- 鼠标模式下指针一直显示成手柄圆环，动鼠标也不会换回系统指针：现在按最后使用的设备切换，
  手柄输入时显示手柄指针，真实鼠标移动后立即恢复系统指针。内嵌 ColorASM 1.4.7 生效。
- 鼠标模式下滚轮上下滚动没有反应（26.3 起游戏改用 SDL 后最明显）：内嵌的 ColorASM
  把滚轮的纵向位移写进了横向字段，游戏收到的纵向滚动量恒为 0，背包、列表等界面滚不动；
  内嵌版本换成 ColorASM 1.4.7 后恢复。GLFW / LWJGL2 的版本不受影响。
- 关闭游戏窗口后进程一直不退出，26.3 会弹「Client shutdown from post-main」崩溃报告：
  内嵌的 ColorASM 里 netty 事件循环是非 daemon 线程且没有关闭，main 返回后 JVM 退不掉。
  ColorASM 1.4.7 改成 daemon 线程，并在退出时关闭连接与线程池。
- 手柄在游戏里改配置（包括拨「鼠标模式单独绑定」）时会把按住的键解错或者一直按着不动：
  规则编号是按列表下标排的，换了一份映射后旧编号对应到了别的规则。现在换表先松开所有动作。
- 游戏退出后它上报的鼠标抓取状态一直留着，下次启动同一个实例会顶着上一局的模式开局：
  通道断开时一并清掉，缓存也不再只增不减。
- 窗口底部的下拉仍会向下展开、被窗口下沿截掉（添加整合包 / 添加资源的项目详情里点版本筛选
  最明显）：弹层方向改成「可视区下方放不下整个弹层，或控件已经在可视区下半屏」就翻到上方，
  选项只有两三个时也不再往下弹。可视区取最近的滚动容器与窗口的交集，不是整页高度 ——
  控件在详情页、弹窗正文里时，边界是那层容器的下沿。翻上去时按上方可用空间给弹层封顶
  （超出部分内部滚动）：版本一多，弹层比上方还高，浏览器会判定"上面也放不下"又翻回下面。
- 网络不通时启动器会把同一批地址反复重试好几分钟：Maven 校验文件逐个等超时，每个文件再
  重试 5 次。现在超时与连不上不再换连接重试，同一主机的其余校验文件直接跳过，单个文件
  最多尝试 3 次；补全失败时主窗口弹错误框写明原因，可以直接点「重试」。
- 实例设置的语言下拉在语言列表加载期间显示成一片空白：下拉的当前值对不上那条「加载中」
  占位项，浏览器就把选中项渲染成空。现在加载期间显示「语言列表加载中…」。
- 关掉「下载整合包」窗口后，主窗口标题栏的下载图标与整合包指示器一直不出来：关窗那一刻
  窗口还活着，重算「整合包窗口是否打开」得到的仍是打开，两个指示器就被藏到下一条整合包
  任务事件。改成窗口真正销毁后再重算，关窗即恢复。

## 0.1.12（开发中）

### 新增

### 改进

- 设置里的 Java 列表改成与实例设置同款的折叠卡片：展开时标题与内容拼成一整块，组内条目
  压在卡片底上；列表外面不再套一层白底面板，组间距回到设置页统一的块间距。
- 没有实例时启动器主页关不掉：顶栏的主页键固定保持按下、点击不再切换（悬停给出原因）；
  删掉最后一个实例、或把启动页设成实例列表，都会回落到主页。

### 修复

- 方块列表的「玩家皮肤」（头颅方块）分类在没有皮肤方块时整栏消失，「添加玩家皮肤」的入口
  跟着一起没了，再也加不回来：这一栏改成常驻，加过头颅之后才出条目。
- 方块列表的头颅单独成一组：原版怪物头颅（僵尸 / 骷髅 / 凋灵骷髅 / 苦力怕）与原版皮肤头
  （玩家头）挪进这一栏，和「添加玩家皮肤」加进来的头颅放在一起，分类名改成「头颅」；
  这一栏里的原版头颅不给删除角标（它们不是皮肤文件）。
- 没设图标的实例在列表里显示成透明方块：占位渐变被占位样式的 `background-image` 抹掉了，
  现在底色与背景图分开写，缺图时照常画渐变块与首字母。
- 下载整合包 / 资源时，目标文件名带 `:` 这类非法字符会让搬运失败（`os error 123`）：
  落盘前先把文件名里的非法字符替换掉；搬运失败的日志同时给出源路径与目标路径。
- 非 Windows 系统（Linux / macOS）源码构建失败：Unix 权限模块漏了 `std::io` 与
  `std::path::Path` 导入，编译停在 `mml-sys`；顺带清掉了 Linux 下的未使用导入 / 变量警告。
- Linux 每次新建窗口都会在日志里刷一条 GTK 线程 panic（`GTK may only be used from the main thread`）：
  KDE Wayland 切换客户端装饰时在 tokio 工作线程上创建 `GtkHeaderBar`，现在排到主线程执行。

## 0.1.11

### 新增

- 主窗口的 RenderDoc 入口改成「使用调试器启动」，一张弹窗里两件事各自开关：
  - **JVM 调试**：填端口（默认 5005）后给游戏加 JDWP。Java 8 写 `address=<端口>`，
    Java 9 及以上自动改成 `address=*:<端口>`；`suspend=n`，游戏照常起来等调试器 attach。
  - **渲染调试**：下拉选 RenderDoc，或选本机安装的 Nsight Graphics（检测到才出现）。
    选中后主按钮变成「使用 renderdoccmd」/「使用 Nsight Graphics」。
  - 另有「生成调试参数」：不启动游戏，给出 qrenderdoc / Nsight「Launch Application」要填的
    可执行文件、工作目录、启动参数与环境变量，可逐项或整份复制。
- RenderDoc 启动的这一局退出后，自动用自带的 `qrenderdoc` 打开本次最新的捕获，
  不用再去 `tools/renderdoc-captures` 里翻文件。
- 本机装了 Nsight Graphics 时，启动器会检测默认安装位置并用它的 `ngfx-capture` 包住游戏，
  捕获落到 `tools/nsight-captures`；没装就只有 RenderDoc 一项。
- 服务器实例的「配置文件」页，文件行多了处理方式下拉：**同步 / 不同步 / 删除该文件**。
  选「删除该文件」时它不进包，客户端下次同步按清单里的 deleteFile 条目删掉这个路径，
  同目录其他文件不动；标记随生成选项保存，改回「同步」就不再删。
- 服务器实例的模组表新增「说明」列：填的文字写进清单的 `Text`，玩家更新可选模组时能在弹窗里
  看到；填过的内容随生成选项保存，下次打开自动回填。
- 服务器实例的配置 / 模组页加了改动回顾：打开时按上次生成的快照对比，新增绿、修改黄、
  删除红；配置页可以切「普通 / 分组」，分组把改动放进新增 / 修改 / 删除三组。
  两页都加了搜索框；配置页还能手动添加自定义条目（额外同步一个文件，或删除客户端的某个文件）。
- 服务器实例「配置文件」页的普通视图改成一张表，「现有文件」「自定义文件」作为表内分组行
  （与资源管理模组的表格模式一致，带箭头与项数，可收起）；表格底部的添加条里
  可选「选择文件」或「输入内容」——输入的文字直接写进输出文件夹，按普通文件条目下发，
  客户端不需要新逻辑；列表里添加的行绿底、删除的行红底。
- 启动实例时本机没有所需版本的 Java：主窗口弹「缺少 Java」提示，点「下载 Java」直接
  打开 Java 下载窗口并预选这个主版本，系统和架构仍按本机自动选。
- 导入文件夹时，如果源目录带 assets / libraries，会先问是否把它们复制到启动器自己的
  assets / libraries；不复制则首次启动重新下载。共用数据只在第一个实例上合并一次。

### 改进

- 主窗口的实例列表去掉「平铺」视图：设置与首启向导里只剩分组 / 列表两种；分组模式向右占满时
  也保持列表行，不再切成图标卡片。旧配置里选过平铺的自动落到分组。
- 所有压缩 / 打包操作都会跳过系统垃圾文件：macOS 的 `.DS_Store` / `._*` / `.Spotlight-V100`、
  Windows 的 `Thumbs.db` / `desktop.ini`、Linux 的 `.directory` / `.Trash-*` 等都不再进包；
  云同步也不再把它们写进清单。实例导出（整份与勾选）、服务器包、存档备份与自定义主题包脚本都适用。
- 服务器实例清单：`Archives` 条目新增 `Action`，取值 `extract` / `deletePath` / `deleteFile`；
  后两种只带 `Path`，分别删掉整个目录与单个文件，不再用空压缩包 + `Over`；所有字段始终写出（false / `null` 也照写，
  不再按默认值省略），清单与本地状态 JSON 改成紧凑格式。`Files` 条目新增 `Text` 模组说明；
  发布清单去掉了 `Skipped` 字段，
  可选模组的跳过记录改存实例的 `gui_setting.json`（`ServerPack.Skipped`），仍然是换内容才重新询问。
- 服务器实例不再生成 HMCL 的 `server-manifest.json`：HMCL 改用「生成服务器包」的 MMC 包。
  包内 `mml-server-sync.jar` 与 `server.json` 放进 `.minecraft`，`instance.cfg` 的 agent 改成
  相对路径；MultiMC / Prism / HMCL 导入后都能直接同步，M²L 仍按 `game.json` 自己更新。
- 服务器实例的「配置文件」页：
  - 名称左边恢复勾选框，文件和目录都能勾：目录取消勾选就是「不同步」，父目录整包时把这块
    从包里排出去；勾回来时在整包 / 整目录的上级底下恢复成「跟随上级」。
  - 「同步方式」右边新增「删除原有目录」一列：勾上时客户端先删掉这个目录再解压，目录里多余的
    旧文件不会留下；取消则只覆盖压缩包里的文件。只有自己有压缩包的目录能改，删除目录恒为真；
    「跟随上级」的行显示上层压缩包的设置（灰的），逐文件 / 不同步的行没有这个设置。
  - 「压缩包整包同步」的目录下，子目录可以在同步方式里选「不同步」把它从父包排出去，
    也可以单独选方式、自己成包；下拉里多一项「跟随上级」，默认就是它。
    「逐文件整目录同步」仍锁住子目录。
  - 上级目录选「不同步」后，子目录不再跟着整棵锁死：同步方式下拉里仍可选「删除目录」，
    让客户端把这个子目录单独清掉；文件照旧不能勾选。
  - 表头「同步方式」改成左对齐，「大小」一列居中；底部两行说明去掉。
- Java 安装 / 资源下载 / 整合包安装三个进度弹窗收成同一套：同样的任务行、总进度与
  「清除已完成 / 关闭」底栏，行内统一显示项目图标，状态文案贴进度条右侧并固定宽度；
  Java 安装任务也补上了 Java 图标，不再只有文字。
- 设置里的 Java 列表改成按发行商分组：从 `java -version` 的运行时行识别 Oracle / Zulu /
  Temurin / Semeru 等，OpenJDK 与 Java 固定排在最后；分组顺序和组内版本顺序都固定，
  不再随扫描顺序变化。
- 列表模式的启动区调整：原来的「调试器启动」图标换成「打开文件夹」；调试启动挪到
  启动按钮右侧的箭头里，外观仍是一颗按钮、没有分隔线，箭头压在右端——点左/右分别启动、
  出菜单，菜单只有「调试启动」一项，选择后仍进原来的调试器弹窗。分组模式的启动按钮
  也改成同一套，按钮文字整体居中。
- 主窗口分组模式占满窗口后，实例仍用未占满时的行外观，只是按窗口宽度一行排多个
  （每列约 280px），不再变成小卡片；点「占满 / 收回」时侧栏宽度与右侧详情同时做
  0.3s 过渡，右侧详情保持原宽度往右推出 / 滑回，不跟着缩放。
- 账户的皮肤预览改成左侧整块白底卡片：3D / 2D 开关放进卡片左上角，预览区铺满剩余高度，
  不再是一个开关加一张独立预览卡。

  会自建一个空窗口，而命令的输出都走管道进了运行日志，窗口里什么都没有；脚本里的交互式提问
  又在那个看不见的窗口上等按键。现在命令以无窗口方式启动，stdin 接空设备。
- 启动前 / 后命令的输出不是实时的：Python 往管道写是块缓冲，整段日志要等进程退出才一次性出现。
  现在给命令补上 `PYTHONUNBUFFERED=1`；输出编码按实例的「日志编码」设置来，
  Python 拿 `PYTHONIOENCODING`，读回来也按同一套解，中文不会再整行当作非法数据丢掉。
- 启动前命令跑着的时候点「取消启动」不管用，得等它自己结束。现在会直接结束这条命令
  （Windows 上连带子进程），按取消处理，不再往下启动游戏。
- 命令输出一旦带颜色，之后追加的日志会整片被染成同一个色：Monaco 的装饰默认会跟着
  行尾输入一起变长，而日志追加正好插在最后一行的行尾。现在两种装饰都把粘性钉成
  「不随输入增长」，颜色只在它那一段里。
- 命令的 stdin 原来接空设备，Windows 上空设备算字符设备、`isatty()` 为真，脚本里的
  「按回车键退出…」照样会打印出来。改成接管道并立刻关掉写端，子进程读到的是 EOF。
- 「发现旧数据」弹窗里点「不导入」/「不迁移」后弹窗不收起，还得再点一次「关闭」；
  现在本机没有别的待答来源时点完就收起。
- 分组收起后顶部还钉着该组的粘滞标题；现在已收起的分组不再挂粘滞头，滚过下一组标题才换人。
- 占满窗口时实例卡片拖不动顺序，往上拖也不会自动滚动；现在按卡片左右半区算落点，
  拖到列表上下边缘都能自动滚。
- 双击标题栏最大化会把窗口关掉，下次启动还变成最大化；现在按下后移动超过 4px 才开始拖窗口，
  单击 / 双击都留在页面里处理。
- Java 26 不认 `-XX:+ZGenerational`，选 ZGC 或自动档直接起不来；现在只在 Java 21 / 22 补这个开关，
  23 起不再带，26 能正常启动。
- 自动 GC 不知道版本 JSON 已经带了 `-XX:+UseZGC`，又叠一套自己的；现在版本 / 加载器 /
  自定义参数里已有 GC 时自动档让位。
- 实例设置里换了 Java 有时不生效，以前填过自定义路径的实例会继续用旧路径；
  现在选具体 Java 或自动会清掉旧路径，取 Java 也以名字为准。
- 日志窗口的启动按钮在检查资源 / 下载阶段是禁用的，没法中途停；现在启动中再点一次
  就是取消启动，与主页面的取消口径一致。
- 导入压缩包时不再要求压缩包本身可写：从下载目录、只读位置或杀毒软件锁写的文件导入时，
  过去会报「读取压缩包内容失败（拒绝访问）」；现在探测与导入都按只读打开，只往实例目录写。
- 导入 HMCL 服务器包后转换为 MML 服务器实例：实例目录写出 `server.json`，
  清单里带地址的文件按 `fileApi` 下载并回写在线信息；同时修正 HMCL 清单的 `fileApi` 键名，
  导出的 HMCL 清单能被 HMCL 正常识别。
