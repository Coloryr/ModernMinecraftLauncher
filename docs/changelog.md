# 更新日志

本文件按版本记录可见变化；安装包与校验和见
[GitHub Releases](https://github.com/Coloryr/ModernMinecraftLauncher/releases)。

0.1.x 都是预发布版，标签带 `-pre` 后缀；界面上的「测试版 / 预发布版」徽章只表示构建通道。

## 0.1.6（开发中）

### 新增

- 设置 → 实验性功能：新增「已下载资源」列表。可以查看公共目录里已下载的模组 / 资源包，
  支持搜索、看占用大小、在资源管理器里定位；文件已被删除的条目会标灰。
- 启动时的数据升级界面：旧版下载索引升级到新索引库时显示进度，可以中途停止，下次启动接着做；
  升级期间不能退出启动器，完成后发一条系统通知。
- 资源管理：模组依赖关系图改为占满窗口的子页面，用返回键或 Esc 回到模组列表。

### 改进

- 下载索引改用嵌入式事务库，旧版 `mod_download.json` / `resourcepack_download.json`
  在启动时自动导入并留底，不再整份重写 JSON，崩溃不会留下半截文件。
- 索引查询从「整表加载进内存」改为按键点查：按文件哈希找公共文件、按项目取最近版本都是点查，
  启动不再整表读取。
- 索引写入按批次提交，不再每条记录一次 fsync；存量映射每处理完一个实例落一次盘。
- 存量资源映射会跳过已经映射过的文件，中断后重开可以接着处理，不必重新校验整份哈希。
- 设置「本地文件」的占用统计改用实例的映射记录判断硬链接，不再逐文件打开句柄，大实例从几分钟降到秒级。

### 修复

- 资源映射进行中关闭设置页不再被拦下，关闭启动器仍会拒绝并给出提示。
- 进度条总数为 0 时改为无限滚动，不再显示一条静止的空进度条。
- 启动前检查只修复已经映射过的文件，不再自动把未映射的实例文件搬进公共目录（改由设置里手动执行）。
- 客户端设置锁不再跨安装共用：内部数据目录那份锁文件按运行目录区分，同一台机器上的几个启动器
  各锁各的，不会因为一个上了锁就把另一个也锁上，也不会互相删掉对方的锁。

## 0.1.5

含 0.1.4 未发布的改动，见下一节。

### 改进

- 导入本地压缩包更快：`.zip` / `.mrpack` / `.modpack` 拖入或从命令行给入时按后缀直接进
  「导入压缩包」，不再先开包探测；条目、类型、实例名与是否服务器包由一次开包返回；
  解压改为多线程并行。

## 0.1.4（未发布）

构建失败，没有发出产物；下面的改动随 0.1.5 一起发布。

### 新增

- 资源管理：模组列表与表格给硬链接文件加「硬链接」徽标，同一份数据还挂在公共目录等别的路径上。

### 改进

- 整合包安装进度按「阶段 + 阶段内细项」折算，标题栏指示器、安装条与 Windows 任务栏图标显示
  同一条进度，装完把任务栏进度条收掉。

### 修复

- 修复 1.7.10 / GTNH 整合包启动崩溃：`--userProperties` 只发空对象。
- 修复 1.21+ 整合包启动时 `org.lwjgl.openal` 重复加载的崩溃，按组件冲突处理，对整合包通用。

## 0.1.3

### 新增

- 设置 → 实验性功能新增「资源映射」：下载的模组与资源包先落到运行目录的公共目录，再硬链接进实例，
  同一份文件在多个实例间只占一份空间，公共目录里已有的文件不再重复下载。开启后可以把现有实例里
  带在线信息的模组 / 资源包搬进公共目录并补链，处理时显示进度并暂时禁止退出启动器。
- 启动实例前会检查实例的 `link_info.json`：公共目录缺文件时重新下载，实例里的链接缺失时补链；
  公共目录没有、实例里却有的文件会搬回公共目录，不必重下一遍。

### 改进

- 设置 → 本地文件：「下载内容」可以展开查看 `mods` 与 `resourcepacks` 的占用；
  实例占用不再重复计算硬链接文件。

### 修复

- 删除映射过的模组 / 资源包时同步清掉在线信息与映射记录，启动检查不会再把它们链回来。

## 0.1.2

### 改进

- 只发布 64 位构建：Windows 与 Linux 都保留 x64 / arm64，不再提供 32 位（x86）安装包。

## 0.1.1

### 改进

- 版本号改为从 Git 标签读取，界面显示、安装包元数据与产物文件名同源，不再维护单独的版本文件；
  本版没有功能变化。

## 0.1.0

### 新增

首个预发布版本：

- 实例：新建、导入（文件夹 / 压缩包 / 在线地址）、重命名、分组排序、删除，多个实例可同时运行。
- 加载器：Forge、NeoForge、Fabric、Quilt、Cleanroom、OptiFine、LiteLoader 与自定义加载器。
- 整合包：CurseForge / Modrinth 搜索、详情与按文件安装，带进度与取消。
- 资源管理：模组分组与启用停用、资源包、光影包、存档备份还原、截图、结构文件、数据包、服务器列表。
- 账户：微软 OAuth、Nide8、Authlib-Injector、LittleSkin 与自建 LittleSkin、离线账户（需先登录过微软账户）。
- 下载与渲染：多线程断点续传下载器；从客户端 jar 离线渲染方块 / 物品图标；皮肤 / 披风 / 头像的 2D / 3D 绘制。
- 迁移与联机：ColorMC / `.minecraft` 数据迁移；陶瓦联机与映射大厅预留。
- 分发与统计：五种实例导出格式、实例信息、服务器包与服务器实例；每日游玩时间与启动统计。
- 界面：多窗口 / 单窗口、明暗与跟随系统、中英双语；自定义主页面、样式包与整页主题。
