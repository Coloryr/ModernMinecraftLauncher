# MML 启动器使用指导手册

M²L（Modern Minecraft Launcher）是一个 Minecraft 启动器。它把"一个游戏实例"从创建、装加载器、
装整合包，到日常的资源管理、启动、看日志、改配置都收在一个界面里；账户、Java、下载各有独立窗口。

- 想先看"有哪些功能"：见 [功能一览](features.md)。
- 想参与开发或自行构建：见仓库根目录 [README.md](../README.md) 与 [AGENTS.md](../AGENTS.md)。

## 1. 第一次启动

程序启动后会在**运行目录**创建自己的数据（Windows 默认是程序同级的 `mml/`，安装版可能由
数据目录里的 `run` 文件指到别处；Linux 是 `~/.mml/`，macOS 是 `/Users/shared/mml/`；
见 [数据与备份](#10-数据与备份)）。
第一次使用建议按这个顺序：

1. **设 Java**：主界面 → 设置 → **Java** → 自动扫描 / 手动添加 / 下载 Java。
   启动器只认它扫描到或你手动指定的运行时；版本对不上时启动会直接报错。
2. **加账户**：顶栏的账户选择器 → 「管理账户」打开账户窗口 → 添加。离线账户填名字即可；
   微软账户走设备码登录；LittleSkin、外置登录、统一通行证按窗口里的字段填地址。
3. **建实例**：主界面「添加实例」→ 新建，依次选版本类型、游戏版本、加载器与加载器版本。
   已有整合包就改用压缩包 / 文件夹 / 在线地址导入。
4. **启动**：在列表里选中实例，点启动。首次启动会补全核心、运行库与资源文件，耗时取决于网络。

如果本机装过 ColorMC，启动时还会问一次是否把它的数据迁移过来。

## 2. 界面与窗口

- **主窗口**：左侧实例列表（分组 / 平铺 / 列表三种视图，设置里切），右侧是选中实例的详情与设置；
  顶栏有账户选择器、启动器主页、设置 / 统计 / 收藏 / 帮助入口，以及下载与整合包任务指示器。
- **多窗口 / 单窗口**：设置 → 界面 → 窗口模式。多窗口下资源管理、日志、配置文件等各自是独立窗口；
  单窗口下它们变成应用内页面，下载与安装进度改以悬浮弹窗显示。切换后需要重启程序。
- **一个实例一个窗口**：资源管理、配置文件、游戏日志、添加资源四类窗口按实例区分，
  同一实例重复打开只会聚焦已有窗口。

## 3. 实例

- **新建 / 导入**：添加实例窗口有四种方式——新建、压缩包、文件夹、在线地址。
  压缩包支持 CurseForge、Modrinth、MMC / Prism、HMCL、HMCL 服务器包、本启动器导出的实例包，
  以及其它启动器的 `.minecraft` 目录包。
- **分组与排序**：实例可拖到别的分组、组内拖动排序；分组标题也能拖。右键分组「全选」进入多选，
  再右键实例做批量操作。
- **详情区**：实例设置（版本 / 加载器 / 内存 / 启动参数）、自定义执行、自定义 JSON、自定义服务器、
  游戏内代理都在这里；整合包实例还能「检查更新」。
- **导出**：详情区的导出按钮把实例打成 CurseForge / Modrinth / MMC / HMCL 整合包。
- **删除**：进系统回收站；实例目录一起删。

## 4. 资源与整合包

选中实例，点详情区的「资源管理」，左侧七个分类：

| 分类 | 常用操作 |
| --- | --- |
| 模组 | 启用 / 禁用、分组、备注、依赖检测、依赖图、更新检查、自动标记 |
| 存档 | 编辑 `level.dat`、备份 / 还原、改配置、删除 |
| 材质包 | 启用 / 禁用、删除（当前有已知问题，见 [features.md §20](features.md#20-疑似缺陷待实机确认)） |
| 截图 | 预览、复制、删除、清空 |
| 服务器 | 增删改、MOTD 查询、导入 / 导出列表 |
| 光影 | 设为当前光影、删除 |
| 结构 | 查看详情、删除 |

- **加资源**：资源管理窗口的「下载资源」打开添加资源窗口，按类型在线搜索
  （CurseForge / Modrinth），自动处理前置依赖，下载后写回在线信息。
- **装整合包**：添加实例窗口的整合包入口（「下载整合包」），按项目安装并自动建实例；
  中途取消会删掉半成品。
- **升级整合包**：实例详情区「检查更新」，按新清单增删模组，自己手动放进 `mods` 的模组不动。

## 5. 账户与皮肤

- 支持离线、微软（OAuth 设备码）、LittleSkin、自建 LittleSkin、外置登录（Authlib-Injector）、
  统一通行证（Nide8）六种账户。
- 账户窗口可切换当前账户、刷新令牌与皮肤、删除账户；离线账户能改名与改 UUID。
- 皮肤窗口支持 2D / 3D 预览、多皮肤多披风（微软）、上传本地皮肤与装备披风。
- 设置 → 客户端设置里可以开**登录方式锁定**，只允许添加指定类型 / 服务器的账户。

## 6. Java

设置 → Java：

- **自动扫描**本机已装的 Java；也可以扫描指定目录、手动添加可执行文件。
- **下载 Java**：从 Adoptium / Zulu / OpenJ9 / Foojay 选 JDK 或 JRE、主版本、系统与架构，
  下载后自动解包并注册。
- 列表里可以删除单个或全部；启动时按实例需要的版本挑最合适的一个。

## 7. 下载

- 下载窗口显示任务、文件与线程的进度、速度、失败数；支持全局暂停 / 继续 / 取消。
- 下载器按文件做断点续传与哈希校验（MD5 / SHA1 / SHA256 / SHA512 等），上游没给哈希时跳过。
- 关掉下载窗口不影响后台下载；单窗口模式下它是悬浮弹窗。

## 8. 设置

设置窗口分八页：

| 页 | 主要内容 |
| --- | --- |
| 界面 | 语言、字体、动画、主题与强调色、窗口模式与材质、启动页、列表视图、背景图、自定义 CSS / 整页界面 |
| Java | 扫描、添加、下载、删除 Java |
| 网络与下载 | 下载源与线程、代理、DNS、检查与 SHA1 校验开关 |
| 游戏启动 | 窗口大小、内存、GC、ColorASM、JVM / 游戏参数、启动前后命令 |
| 皮肤与头像 | 头像 / 皮肤 / 披风的 2D、3D 展示档位 |
| 客户端设置 | 服务器与自动进服、MOTD、登录与实例锁定、自动进存档确认、自定义音乐、自定义主页、游戏标题 |
| 本地文件 | 运行目录各文件夹占用，缓存可就地清理 |
| 实验性功能 | 管理员启动、URI 启动、沙盒启动（仅落配置，尚未接线） |

标题栏的搜索框可以直接搜设置项，命中会切页并高亮分组。

## 9. 自定义界面

三种换皮互相独立，都打包成 zip 导入：

1. **自定义主页面**：只换主窗口的主页内容，包根放 `index.html` 或 `custom.js`；
   页面里可以用 `window.mml` 调命令、订阅事件。入口在设置 → 客户端设置。
2. **自定义 CSS**：给内置界面换皮，可装多份、分别启用与排序；包根放 `custom.css`，
   可选 `custom.js` 做更细的替换。入口在设置 → 界面。
3. **完全自定义界面**：整页替换主窗口，包根放 `index.html` 或 `custom.js`；
   `custom.js` 还能按窗口类型替换单个窗口组件。入口在设置 → 界面。

页面挂掉时可以在设置里关掉开关，或直接删除 `custom_ui/` 下的包恢复内置界面。

## 10. 数据与备份

运行目录默认在 Windows 是程序同级的 `mml/`（安装版可能由数据目录里的 `run` 文件指定；
Linux `~/.mml/`，macOS `/Users/shared/mml/`），里面主要这些东西：

- `minecraft/`：版本、运行库、资源与全部实例（`instances/<名字>/`）；
- `java/`：下载的 Java；
- `cache/`：下载缓存与 WebView2 数据；
- `logs.log`：启动器日志；
- `gui_config.json` / `config.json` / `window_save.json` 等配置。

完整清单见 [features.md §0.1](features.md#01-目录与配置文件)。

**备份**：直接复制整个运行目录即可。实例也可以单独导出成整合包；存档在资源管理里有备份 / 还原。

## 11. 遇到问题

1. **先看日志**：启动器日志在运行目录的 `logs.log`；游戏日志在实例的日志窗口（可上传 mclo.gs）。
   游戏异常退出会自动打开日志窗口，并优先展示最新的崩溃报告；没有崩溃报告时回到运行日志并滚到底。
2. **启动失败**：确认 Java 版本、账户状态与实例完整性；启动器会在启动前自动补全缺失文件。
3. **界面异常**：如果是自定义 CSS / 整页界面导致的，先在设置里关掉对应开关。
4. **帮助窗口**：主界面顶栏的「帮助」有 FAQ、开源许可与第三方服务说明。
5. **反馈**：带上 `logs.log` 与复现步骤到 GitHub Issues。
