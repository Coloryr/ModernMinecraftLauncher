# M²L 启动器软件手册

M²L（Modern Minecraft Launcher）是一个 Minecraft 启动器。它把“一个游戏实例”从创建、装加载器、
装整合包，到日常的资源管理、启动、看日志、改配置都收在一个界面里；账户、Java、下载、联机各有
独立窗口。

本手册按“第一次启动 → 日常使用 → 设置与排错”的顺序写，既讲功能在哪里，也讲推荐的操作顺序。

> **重要限制**：未登录过微软正版账户时，**不能启动离线账户**。请先在账户窗口添加并登录一个
> 微软账户；登录过之后，离线账户才可用。前端会禁用启动按钮，Rust 后端的启动命令也会再次拒绝。

- 想参与开发或自行构建：见[开发与构建](development.md)。
- 开源许可与第三方组件：见[开源许可](licensing.md)。

> 当前发布版本从 **v0.0.1** 开始。界面上的「测试版 / 预发布版」徽章只表示构建通道，不代表功能差异。

## 1. 第一次启动

程序启动后会在**运行目录**创建自己的数据。Windows 默认是程序同级的 `mml/`，安装版可能由数据
目录里的 `run` 文件指到别处；Linux 是 `~/.mml/`，macOS 是 `/Users/shared/mml/`。完整目录见
[数据与备份](#17-数据与备份)。

第一次使用建议按这个顺序：

1. **加账户**：点顶栏的账户选择器，进入「管理账户」后添加账户。微软账户走设备码登录；
   LittleSkin、自建 LittleSkin、外置登录、统一通行证按窗口里的字段填写地址。
   **如果打算用离线账户，必须先登录过一个微软账户**；没有正版登录记录时离线启动会被拒绝。
2. **建实例**：在主界面点「添加游戏实例」，从头新建，依次选择版本类型、游戏版本、加载器与
   加载器版本；已有整合包就改用压缩包 / 文件夹 / 在线地址导入。
3. **启动**：选中实例点启动。启动器会自动扫描 Java 并按实例需要的版本挑选；自动找不到合适的
   运行时时，再到设置 → **Java** 手动指定或下载。首次启动会补全核心、运行库与资源文件，
   耗时取决于网络。

如果本机装过 ColorMC，启动时还会询问是否把它的数据迁移过来，见[数据迁移](#15-数据迁移)。

## 2. 界面与窗口

### 2.1 主窗口

主窗口由三块组成：

- **顶栏**：启动器主页开关，设置 / 统计 / 收藏 / 帮助四个入口，整合包安装、下载、资源下载三个
  进度指示器，账户选择器，以及窗口按钮。
- **侧栏**：实例列表。可在设置里切换**分组 / 平铺 / 列表**三种视图；侧栏可收起、可换到右侧。
  顶部搜索框按实例名或版本过滤；底部可以「添加实例」「添加分组」。
- **内容区**：没有选中实例时显示启动器主页（新闻、快捷入口）；选中实例后显示实例详情与设置。

启动器主页还会显示当前选中实例的快捷启动卡、Mojang 新闻，以及「联机大厅」「方块列表」两个入口。
一个实例都没有时，主页显示空状态引导，只保留「添加游戏实例」和「添加账户」两个按钮。

### 2.2 多窗口与单窗口

设置 → 界面 → **窗口模式**：

- **多窗口**：资源管理、日志、配置文件、添加资源等窗口各自独立，可并排摆放。
- **单窗口**：这些窗口变成应用内页面，带返回栈；下载、安装、资源下载进度以悬浮弹窗显示。

切换窗口模式会立即重启启动器。窗口位置、大小、最大化状态会记住；资源管理、配置文件、游戏日志、
添加资源这四类窗口按实例区分，同一实例重复打开只会聚焦已有窗口。

### 2.3 拖放

可以把文件或文件夹拖进窗口：

- 整合包压缩包、实例文件夹、服务器包 → 主窗口或添加实例窗口；
- `.url` / `.webloc` 登录快捷方式 → 账户窗口，自动预填外置登录地址；
- 资源文件（模组、资源包、光影、存档、数据包等）→ 资源管理窗口对应分类。

资源窗口只接文件，不接受目录或网页文本；同名冲突会让你逐次选择跳过、重命名或覆盖。

## 3. 游戏实例

### 3.1 新建实例

「添加实例」窗口有四种方式：**从头新建 / 导入压缩包 / 添加文件夹 / 在线实例**。

从头新建：

1. 选版本类型：正式版、快照、旧版 Beta / Alpha 或全部类型。
2. 选游戏版本。
3. 选加载器：原版、Forge、Fabric、Quilt、NeoForge、Cleanroom、OptiFine、LiteLoader、自定义。
4. 选加载器版本；自定义加载器需要选择本地 `.jar`。
5. 填实例名称和分组，点「创建实例」。

支持的加载器覆盖 9 种，其中 Cleanroom 是 1.12.2 的 Forge 分支，自定义加载器使用本地 jar。
某个游戏版本支持哪些加载器、以及加载器版本列表，都会在窗口里即时查询，可点刷新。

### 3.2 导入实例

**导入压缩包**支持以下来源，选择压缩包后会自动识别类型并预填：

| 来源 | 说明 |
| --- | --- |
| CurseForge | `manifest.json` 整合包，安装时按清单补充模组 |
| Modrinth | `.mrpack` 整合包 |
| MMC / MultiMC / Prism | 其它启动器的实例包 |
| HMCL | HMCL 导出包 |
| HMCL 服务器包 | 服务器分发包，按服务端清单安装 |
| 本启动器导出的实例包 | 「直接压缩」生成的 zip，可原样拖回导入 |
| 其它 `.minecraft` 目录包 | 自动判断版本隔离并挑主版本 |

**添加文件夹**可以扫描目录并识别出多个实例，勾选要导入的那些即可。**在线实例**填入整合包下载地址
后直接下载安装。导入中可以取消；重名会询问覆盖或自动改名；添加成功后可以继续添加下一个。

### 3.3 管理实例列表

- **三种视图**：分组（按分组铺开）、平铺（图标网格）、列表（只显示当前选中的实例）。
- **分组**：添加 / 重命名 / 删除；实例可拖到别的分组，组内可拖动排序，分组标题本身也能拖。
- **右键菜单**：启动、打开文件夹、查看日志、修改配置文件、换图标、重命名、删除、导出；
  分组菜单支持全选、启动全部、转移分组、删除分组。
- **多选**：右键分组「全选」进入多选，然后批量改分组、批量删除、批量启动。
- **单个实例**：启动 / 停止、重命名（实例目录一起改）、删除（进系统回收站）、打开目录、裁剪图标。
- **实例锁定**：在设置 → 客户端设置里锁定一个实例后，主窗口只能操作它，列表固定为列表视图，
  不能增删实例或分组；锁定实例被删除时整块显示错误页。
- **重启提示**：正在运行的实例带小圆点；同一实例不能重复启动，不同实例可以同时运行。

### 3.4 实例设置

选中实例后，内容区展示实例详情：

- **元信息**：版本类型、游戏版本、加载器、加载器版本、游戏内语言、日志编码、自动打开日志窗口、
  整合包类型。整合包实例的版本与加载器由整合包决定，不能单独改。
  游戏内语言目前只保存选择，暂未写入启动参数，见[已知限制](#19-已知限制)。
- **启动设置**：窗口大小、内存、Java、GC 模式、ColorASM、JVM 参数、游戏参数、游戏内代理、
  启动前 / 启动后命令、自定义 JVM 环境变量。
- **自定义执行 / 自定义 JSON**：替换启动命令，或使用 `json/` 目录里的自定义启动配置。
- **自定义服务器**：服务器地址、启动时自动加入、MOTD 卡片；1.20+ 使用快速进入服务器。
- **其它**：实例图标、备注、游玩时长、MOTD；整合包实例有「检查更新」。

启动前 / 后命令支持 `%JAVA_LOCAL%`、`%GAME_DIR%`、`%GAME_NAME%`、`%JAVA_ARG%` 等占位符；
启动前命令可以选择与游戏同时运行。

### 3.5 启动与停止

点启动后，启动器依次完成：

1. 检查版本号、加载器版本、自定义加载器文件是否存在；
2. 按账户类型刷新令牌，失败时询问是否降级为离线；
3. 服务器包实例先按远端清单同步文件；
4. 检查并补齐核心、运行库、资源文件与整合包模组（可分别开启 SHA1 校验）；
5. 选 Java：先看实例指定的路径 / 名称，否则自动扫描并按版本要求挑选；
6. 组装 JVM 参数与游戏参数，处理启动前命令，拉起游戏；
7. 游戏退出后执行启动后命令，记录统计与日志。

启动日志里的 uuid / accessToken 会打码。实例运行中可以停止；异常退出会自动打开日志窗口。

> 离线账户的启动前提是**本机至少登录过一个微软正版账户**；只添加过皮肤站 / 外置登录账户不算，
> 启动器会直接拒绝并提示。

### 3.6 导出实例

实例详情区的导出按钮，或右键菜单「导出」，打开「导出实例」窗口。

**五种格式**：

| 格式 | 用途 |
| --- | --- |
| 直接压缩 | 以实例目录为根整份打成 zip，可拖回本启动器导入；`.minecraft` 会展开，实例根目录下 `.minecraft` 之外的文件必选 |
| CurseForge | 生成 CurseForge 整合包，清单里只写项目号 / 文件号；下载地址在该格式下不生效 |
| Modrinth | 生成 `.mrpack`，填了下载地址的模组写进清单，没填的随 overrides 打包 |
| MMC | 整包实例，供 MultiMC / Prism 导入；自定义加载器会丢失 |
| HMCL | 整包实例，供 HMCL 导入；自定义加载器会丢失 |

窗口有三个页签：

- **整合包信息**：包名、作者、版本、简介。
- **模组**：列出带在线来源的模组，可改项目号 / 文件号；只有 Modrinth 会多一列下载地址。
  编号不成立的模组会灰掉，按本地文件打进包。
- **文件**：懒加载文件树，勾选即打包，取消勾选即排除。日志、崩溃报告、缓存、临时目录、备份默认
  不勾选。

压缩等级可选轻量 / 默认 / 固实。导出位置不能选在实例目录内；实例含符号链接时会被拒绝。
导出中可以取消，关闭窗口会先确认。

窗口右上角的「生成实例信息」会导出一份 JSON，只包含实例名、版本、加载器、整合包来源和模组文件名，
不包含账户、Java 路径、服务器地址、环境变量或代理凭据，适合贴给别人排查。

服务器包是另一种分发格式，见[服务器包](#16-服务器包)。

## 4. 资源管理

选中实例后点详情区的「资源管理」，打开该实例的资源窗口。窗口锁定当前实例，不再切换；左侧有
七个分类，顺序可以拖动调整，并记住上次打开的分类。列表刷新、切分类不会重新扫描；删除类操作
默认进系统回收站。

| 分类 | 主要内容 |
| --- | --- |
| 模组 | 启用 / 禁用、分组、备注、依赖检测、依赖图、更新检查、自动标记、导出列表 |
| 存档 | 编辑 `level.dat`、备份 / 还原、改配置、删除；下含数据包子页 |
| 资源包 | 启用 / 禁用、删除；兼容旧称“材质包” |
| 截图 | 预览、复制、删除、清空 |
| 服务器 | 增删改、MOTD 查询、导入 / 导出列表 |
| 光影包 | 设为当前光影、取消、删除 |
| 结构文件 | 查看详情、删除 |

### 4.1 模组

- **两种视图**：列表和表格。表格支持表头排序、拖动列宽（落盘保存）、多选和就地编辑备注。
- **启用 / 禁用**：只改文件名后缀，不移动文件。删除进回收站。
- **搜索**：按名字、modid、文件名、作者、版本、简介过滤。
- **备注**：右键或表格内直接编辑，随实例保存。
- **自定义分组**：新建 / 重命名 / 删除；一个模组同时只属于一个组，移进分组会顺带启用。
  还有「识别失败」「已启用」「已禁用」三个固定分组。分组块可折叠、可拖动排序。
- **依赖检测**：检查强制前置是否齐全、版本是否满足，按「缺少前置」「前置被禁用」「版本不符」
  分组列出；加载器和游戏自身提供的前置会跳过，内置 jar-in-jar 里的模组算已提供，只有启用的模组
  参与检测。检测结果可以一键复制。
- **依赖图**：右键「依赖图」查看节点与连线，必装和可选前置分色，游戏 / 加载器是虚拟节点；
  双击节点可以换目标，点连线看关系说明。
- **启用 / 禁用的连带处理**：禁用被依赖的模组时会问是否一起禁用；启用缺前置的模组时会问是否
  一起启用。
- **重复安装**：同一 modid 有多个文件同时启用时自动提示，并单独归到「modid 重复」分组。
- **更新检查**：按在线信息查询新文件，弹窗按「当前 → 最新」列出并默认全勾；更新会下载新文件、
  旧文件进回收站，失败保留原文件。
- **替换版本**：把单个模组换成平台上同一项目的其它版本；更新记录按项目保留版本 / 文件号变更历史，
  可筛选、可删除。
- **自动标记**：按 jar 的 SHA512 到 Modrinth 反查项目并写回在线信息，可选择是否覆盖已有条目。
- **导出模组列表**：工具栏「导出模组列表」支持 TXT / CSV / JSON，可勾选字段（名称、modid、版本、
  文件名、作者、简介、网址、来源、项目 ID、文件 ID、SHA1、禁用状态、运行侧、加载器、备注），
  也可以只导出选中的模组。

### 4.2 存档与数据包

**存档**：

- 解析 `level.dat`，显示名字、上次游玩、模式、难度、极限模式、种子、图标、损坏标记和备份数。
- **编辑存档**：改名、游戏模式、难度、极限模式、种子（支持随机）；实例运行中不允许编辑。
- **备份 / 还原**：备份 zip 存到实例 `backup/` 并登记索引；还原前二次确认，旧存档先移入回收站。
- 单行菜单可以编辑、修改配置文件、备份、还原、打开文件夹、删除；批量只有删除。
- 存档名里的 `§` 格式码会按 Minecraft 的颜色规则显示。

**数据包**（存档子页）：

- 落点是 `saves/<存档目录名>/datapacks`，需要先选存档。
- 解析 `pack.mcmeta`；启用状态取自 `level.dat` 的 `DataPacks.Enabled/Disabled`。
- 支持启用 / 禁用 / 删除、批量三种操作、打开目录。删除时会先清掉 `level.dat` 里的引用。

### 4.3 资源包

- 解析 `pack.mcmeta`，简介按界面语言查包内语言表，显示 min/max_format 和 `pack.png` 图标。
- 支持启用 / 禁用、删除、打开文件夹，批量启用 / 禁用 / 删除。
- **注意**：当前版本在启动器里切换资源包可能写错文件，原版实例还可能报错；切换不生效时请在
  游戏内「选项 → 资源包」里操作，见[已知限制](#19-已知限制)。

### 4.4 光影包

- 解析 zip 或目录里的 `lang/*.lang` 取名字与说明；当前光影由 `options.txt` 的 `shaderPack` 判断。
- 设为当前光影、取消（再点一次已选中的那个，写入 `OFF`）、删除、打开文件夹；批量只有删除。

### 4.5 结构文件

- 支持 `.schematic`、`.litematic`、`.schem`（WorldEdit）、`.nbt`（Create）。
- 列表显示名字、作者、描述、尺寸、方块总数、种类数；详情按方块种类计数排序，只读。
- 支持删除、批量删除、打开文件夹。

### 4.6 截图

- 网格列表 + 大图预览；滚轮缩放，放大后可拖动平移，点空白或 Esc 关闭。
- 单张删除、批量删除、清空全部，都进回收站。
- 单张「复制图片」会把原图写进系统剪贴板。

### 4.7 服务器列表

- 读写实例的 `servers.dat`：添加、编辑（名字 / 地址 / 接受材质）、删除。
- 进入分类时会并发查询所有服务器的 MOTD（含 SRV 解析），行内显示能否连上、在线人数。
- 列表上方有 MOTD 卡，显示选中的服务器，可单独刷新；图标用查询返回的 favicon。
- 可以整份导出 / 导入：导出复制 `servers.dat`；导入会先备份，再替换并解析校验，失败时还原。
- 批量只有删除。

### 4.8 拖放导入

- 资源窗口只接文件，目录、网页文本在悬停阶段就不放行；松手后后端还会再探测一次。
- 落点是当前分类对应的目录；数据包页落到所选存档的 `datapacks`。
- 同名冲突会依次询问跳过 / 重命名 / 覆盖；存档包按目录名解压，重名时自动加 ` (1)`。

## 5. 下载、整合包与收藏

### 5.1 添加资源

资源管理窗口的「下载资源」打开添加资源窗口。支持五种类型：模组、资源包、光影包、存档、数据包。

- **来源**：CurseForge、Modrinth；存档只有 CurseForge。
- **筛选**：来源、游戏版本（默认当前实例版本）、排序、分类、加载器（仅模组）、搜索词；每页 20 条。
- **卡片**：显示已安装 / 下载中角标、收藏星标；点卡片进详情看文件列表。
- **前置依赖**：递归解析前置的前置，去重，剔除已安装和自环；必选前置默认勾选且不可取消，可选
  前置默认不勾，每个都可以改版本。可以选择不下载前置（会二次确认）、全部下载或下载所选。
- **下载**：按类型落到对应目录；同一实例同一项目文件不能重复下载；进度通过事件推送并显示进度卡。
- 下载完成后写入实例的在线信息（资源列表里的来源、项目号由此而来），**不会自动启用**。

### 5.2 下载整合包

添加实例窗口的「下载整合包」按 CurseForge / Modrinth 项目安装，自动建实例。

1. 选择项目版本和安装分组（可选已有分组或现建）。
2. 下载整合包 → 读清单 → 识别版本与加载器 → 建实例（写图标）→ 解压 `overrides/` →
   写入在线信息 → 统一下载 → 完成。
3. 进度按阶段显示，每条任务可以取消；中途取消或失败会删掉半成品实例。

窗口关掉后任务继续跑，进度改到标题栏指示器和悬浮弹窗；装完后主界面刷新并选中新实例。

### 5.3 资源收藏

- 数据存在运行目录的 `collect.json`；星标来自资源列表和整合包列表。
- 类型过滤：整合包、模组、资源包、光影包；一个默认分组加若干自建分组，可增删、可折叠。
- 把卡片拖到分组即移入；多选时整批移动；支持全选当前可见、移动到分组、删除。
- 右键可以打开项目页、添加到分组、移出分组或从收藏删除。
- 点卡片即下载：整合包直接进详情；其它资源先选实例，再跳到添加资源窗口。

### 5.4 整合包更新

- 实例详情区的「检查更新」按实例记录的整合包来源查新版本，只对 CurseForge / Modrinth 实例可用。
- 查到后弹确认窗（新版本号 / 发布时间），确认后登记升级任务，进度走标题栏的整合包指示器。
- 升级按新版本清单增删模组、覆盖整合包自带文件；**你自己手动放进 `mods` 的模组不会被动**。

### 5.5 下载管理

- 下载窗口显示任务、文件、线程的进度、速度、失败数；全局暂停 / 继续 / 停止。
- 下载器按文件断点续传，支持 MD5 / SHA1 / SHA256 / SHA512 / SHA1+SHA256 / SHA1+SHA512 校验；
  上游没给哈希时跳过，并额外检查字节数与 `Content-Length`。
- 单文件累计失败超过 5 次会放弃并删掉残缺文件；主动取消不计入失败数。
- 任务全部结束且无失败时自动关窗；关掉下载窗口不影响后台下载。
- 单窗口模式下下载管理是悬浮弹窗。
- 目前只有全局暂停 / 继续 / 停止，不能单独暂停某一个任务；添加资源任务也不能取消，见
  [已知限制](#19-已知限制)。

## 6. 账户与皮肤

### 6.1 账户类型

| 类型 | 登录方式 | 说明 |
| --- | --- | --- |
| 离线 | 本地生成 UUID，可改名 / 改 UUID | 唯一可编辑账户信息的类型 |
| 微软 | OAuth 设备码：显示代码 → 打开浏览器 → 轮询 → Xbox / XSTS / Minecraft 令牌 | 可取消；令牌约 24 小时，401/403 自动刷新 |
| LittleSkin | 官方站用户名密码 | |
| 自建 LittleSkin | 站点地址必填 | 自动去掉 `/api/yggdrasil`、`/user` 并补尾斜杠 |
| 外置登录（Authlib-Injector） | 认证服务器地址必填 | 刷新前先 validate |
| 统一通行证（Nide8） | 服务器 ID 作认证地址 | |

> **离线启动限制**：本机从未登录过微软正版账户时，离线账户不能启动。请先添加并完成一次
> 微软账户登录；皮肤站、外置登录、统一通行证都不算正版登录记录。

### 6.2 账户窗口

- 支持平铺 / 列表 / 详情三种展示视图，可按类型筛选、搜索。
- 双击切换当前账户；也可以刷新令牌、刷新皮肤、重新登录、删除账户。
- 离线账户可以改名和改 UUID（含随机 v4）。
- 列表按最后登录时间倒序。
- 拖入 `.url` / `.webloc` 登录快捷方式，会自动预填外置登录地址。

**登录方式锁定**：设置 → 客户端设置 → 登录方式锁定。打开总开关并配置条目后，只能添加列表中的
登录类型；外置登录 / 自建皮肤站 / 统一通行证还会锁定服务器地址。适合服主统一分发整合包。

**联机大厅账户锁**：打开联机大厅后会验证并锁定当前微软正版账户，大厅关闭前不能切换或删除该账户。

### 6.3 皮肤与披风

- 微软账户支持多皮肤、多披风；其它在线账户通常是单皮肤、单披风。
- 3D 预览用 skinview3d：2D / 3D 切换、旋转、缩放、8 种动画和不播放、名牌与披风开关。
- 2D 视图可以拖拽平移、缩放；皮肤型号有自动检测、经典、纤细、1.7 旧版四档。
- **装备皮肤 / 披风、上传本地皮肤**只对微软账户开放；第三方账户会给出明确错误。
- 可以打开皮肤站网页：LittleSkin 官网、Nide8 服务器页、外置登录站点根。
- 头像、皮肤、披风、鞘翅的 2D / 3D 图由壳层自渲染，贴图按内容 SHA1 缓存，跨账户只存一份。

## 7. Java 运行时

启动器在启动游戏时会自动扫描 Java，并按实例需要的版本和架构挑选；通常不需要手动设置。

设置 → Java 可以管理运行时：

- **扫描本机 Java**：Windows 查 `where javaw.exe` 和注册表，Linux 查 `which` / `update-alternatives` /
  `pacman` 与常见目录，macOS 查 `/usr/libexec/java_home` 和标准目录；判定靠执行 `java -version`。
- **手动添加**：选择 Java 可执行文件，自动探测名称。
- **扫描指定目录**：包含子目录。
- **从压缩包导入**：zip / 7z / gz / tar，带解包进度。
- **下载 Java**：Adoptium、Zulu、OpenJ9、Foojay 四个源；可选 JDK / JRE、主版本、系统、架构；
  下载后自动解包并注册。
- 可以删除单个或全部。启动时按实例需要的版本过滤架构，精确匹配或取不低于要求的最高版本。

## 8. 配置文件编辑

资源管理窗口的「修改配置文件」打开配置文件窗口。

**文件范围**：实例的 `options.txt`、`config/`、`kubejs/`、`local/`，或某个存档目录下的全部文件
（含数据包、`level.dat`、区域文件）。路径一律相对所选来源，并阻止路径穿越。

**按扩展名识别类型**：json、json5、toml、yaml、properties、xml、javascript、snbt、NBT、
区域文件 `.mca`、图片、压缩包；其余按纯文本处理。

| 视图 | 能做什么 | 能否保存 |
| --- | --- | --- |
| 文本 | Monaco 编辑，按语言着色 | 可以，保存时走行级差异 |
| NBT | 树形编辑：改标量、新增 12 种类型、改名、删除；数组按下标 | 可以，写回会话里的 NBT 句柄 |
| 区域文件 `.mca` | 查看区块表（下标 / X / Z / 扇区 / 占用 / 时间戳），按坐标或 id 查找 | 只读 |
| 图片 | 直接显示，上限 4 MiB | 不可以 |
| 二进制 | 十六进制分页，单页 64 KiB | 不可以 |

- 文本保存前会做前端自检和后端基准 SHA1 核对；NBT 写回前核对 SHA1、mtime 和长度，只成功一半
  就丢弃会话。
- 文本与 NBT 树上限 4 MiB；NBT 数组最多 1024 个元素可展开 / 增删。
- 文件树可搜索，命中目录会自动展开；有未保存改动时保存键会变强调色。
- 保存按钮在右上角，也可以按 `Ctrl+S` / `Cmd+S`。
- `.mca` 页的「查找」会扫存档内的区域文件，命中后切到对应文件并翻到那一块。

## 9. 游戏日志与崩溃分析

资源管理窗口的「查看日志」打开该实例的日志窗口。

- **实时日志**：订阅游戏输出，按实例过滤，内存上限 10000 行。
- **历史日志**：实例的 `logs` 和 `crash-reports`，只能打开列表里的文件。
- **筛选**：Info / Warn / Error / Debug / 其它五个等级开关，线程下拉，分组下拉；换行和自动下拉
  开关；页内查找。
- 设置保存在实例的界面设置里；换行是全局偏好，与配置编辑器共用，`Alt+Z` 可切换。
- **上传 mclo.gs**：上传整份日志（不是筛选后的行），确认后上传，成功后自动复制地址。
- **异常退出**：退出码非 0 时自动打开日志窗口；2 分钟内生成过崩溃报告就打开最新那份，否则回到
  运行日志并滚到底。
- **崩溃分析**：打开历史日志或崩溃报告时自动分析，正文上方给出主因（缺前置、依赖版本、加载器
  混装、Mixin、OOM、渲染、看门狗、维度等）、把握程度、可疑模组、环境摘要和可展开的日志证据；
  其余结论折在「其它发现」里，可以一键关掉。
- **测试启动 / 停止**：可以直接从日志窗口拉起或结束该实例。

## 10. 方块与物品图标

- 图标不是内置贴图，而是从客户端 jar 现场渲染：版本清单 → 下载 jar → 解包 → 渲染。
  首次进入是「未渲染」态，由界面按钮触发整表渲染；渲染中可取消，关窗会先确认。
- 方块和物品合并成一份列表，顺序等于游戏创造栏顺序；支持按下 / 放下 / 点亮 / 开启 / 打开 /
  伸出 / 激活等特殊形态，也有头颅方块。
- 输出 PNG，固定 256×256，支持 APNG 多帧动画；设为实例图标时可选 16–1024 的边长。
- 界面有未渲染 / 渲染中 / 已渲染三态；分类栏带数量；搜索匹配 id、显示名、分类名；显示尺寸三档；
  详情弹窗可看大图、复制 ID、查看分类。
- **自建分组与收藏**：左栏可新建 / 重命名 / 删除分组、拖拽排序；方块可收藏、可多选设置分组，
  数据存在 `block_groups.json`。
- **设为实例图标**两种：记方块 ID（跟随重渲染自动变）或本地图片裁剪。
- **玩家头颅**：按用户名或 UUID 拉皮肤渲染，可添加 / 删除。
- 首次渲染需要下载客户端 jar 时，会自动打开下载窗口。

## 11. 联机大厅

主页面点「联机大厅」打开。大厅分「陶瓦联机」和「映射大厅」两个页签。

### 11.1 使用条件

- 需要当前账户是**微软正版账户**（OAuth）。打开大厅后会验证并锁定该账户，关闭大厅才解除。
- 首次启动陶瓦会下载并校验官方程序，进度显示在大厅里；之后会显示版本号和公共节点。
- 部分系统或处理器不支持陶瓦联机，会直接提示。

### 11.2 房主

1. 在「游戏实例」下拉里选择要联机的实例。
2. 点「启动游戏」，进入存档后对局域网开放。
3. 回到大厅点「创建房间」。
4. 房间就绪后把邀请码发给朋友；在「公共节点」里可以勾选本次使用的节点。

### 11.3 加入

1. 填入邀请码，点「加入房间」。
2. 连接成功后选择实例并启动游戏；支持自动进服的版本会自动进入房主服务器。
3. 不支持自动进服的版本，可以复制「直连地址」，在游戏多人游戏里手动添加。

房间面板会显示邀请码、直连地址、连接难度和成员列表；可以随时退出房间。关闭大厅会断开本次联机
并解除账户锁定，但已经启动的游戏会继续运行。

「映射大厅」页签目前只有展位和搜索框，后端服务尚未接入，见[已知限制](#19-已知限制)。

  - **启动器管理员启动**：启动器自身以管理员身份运行；

## 13. 界面与外观

### 13.1 主题与语言

- 主题跟随系统 / 浅色 / 深色；跟随系统时监听系统切换。

### 13.2 自定义主页面

设置 → 客户端设置 → 自定义主页面。

- 导入 zip，包根放 `index.html` 或 `custom.js`，可选 `custom.css`。
- 启用后主窗口的启动器主页换成该页面；没导入或关闭开关时回落到内置主页。
- 页面里可以用 `window.mml` 调用命令、订阅白名单事件；包内静态资源随包读取。

### 13.3 样式包（自定义 CSS）

设置 → 界面 → 样式包。

- 包根放 `custom.css`，可选 `custom.js`；可以安装多份，按列表顺序叠加。
- 每条都可以单独启用 / 停用、上移 / 下移、删除。
- `custom.js` 可以改文字 / 类名，也可以把原控件替换成自己的 Vue 组件。

### 13.4 主题包（完全自定义界面）

设置 → 界面 → 主题包。

- 导入一份 `page.zip`，包根放 `index.html` 或 `custom.js`，可选 `custom.css`。
- 启用后整页替换主窗口；`custom.js` 也可以按窗口 kind 替换单个窗口组件。
- 关闭开关或删除包即可恢复内置界面；开发构建的整页右下角还有「退出整页界面」入口。

三种换皮互相独立：装自定义主页面不影响样式包和主题包，主题包开着时自定义主页面仍在它后面。

### 13.5 窗口与背景

- 窗口几何存在 `window_save.json`，按窗口恢复位置、大小、最大化。
- 一个实例一个窗口的四类窗口：资源管理、配置文件、游戏日志、添加资源；同一实例重复打开只聚焦。
- 背景图支持本地文件和网址，后端缩放后下发；有背景时界面表面半透明。

## 14. 游戏统计

顶栏的统计入口打开游戏统计窗口。

### 14.1 汇总

顶部汇总卡显示：当前游戏实例数、已删除实例数、累计启动次数、启动失败次数、累计游玩时长。

### 14.2 游玩时间图

- 可以选择**全部实例**或某个实例，时间段为近 7 / 30 / 90 天，也可以自定义起止日期。
- 图上方显示时间段内游玩时长、有游玩的天数、日均游玩。
- 柱状图按天显示；鼠标悬停看当天时长、启动次数和失败次数。
- **双击某根柱子**会切换到这一天的实例占比环形图，再次选择其它时间段恢复柱状图。

### 14.3 实例表

- 每行显示实例、启动次数、失败次数、游玩时长、最近游玩；行数多时只渲染视口附近，滚动流畅。
- 运行中的实例标「运行中」，已删除的实例保留历史并标「已删除」。
- 窗口打开时每 5 秒刷新；切走或最小化会暂停轮询，切回来补一次。

### 14.4 记录规则

- 进程启动记一次启动，启动失败记失败，游戏退出记游戏结束。
- 每局保存起止时间，后台按 100ms 累加时长，与界面是否打开无关。
- 主窗口关掉后进程留在托盘，计时继续；托盘图标或再次启动 exe 可以唤回界面。

## 15. 数据迁移

- 支持从 **ColorMC** 迁移：启动时探测 ColorMC 工作目录，首次启动询问复制 / 移动 / 不迁移。
- 迁移按顶层条目原样复制或移动，不做字段级转换；同盘移动瞬时，跨盘回退为复制后删源；单文件失败
  不中断。
- 搬完会做兼容性检测，逐个实例用本启动器的解析器验读 `game.json`，并提示哪些数据不会沿用；
  账户文件永不迁移。
- 实例重名时导入的实例自动改名保留两份（如 `Foo` 和 `Foo1`）；uuid 冲突只给导入的实例换新；
  ColorMC 的分组名会合并进分组表，同名组复用。
- 删掉运行目录里的迁移标记文件可以重新触发询问。
- HMCL / MMC / 官方启动器没有专门迁移，请用「添加实例 → 文件夹 / 压缩包导入」把实例搬进来。

## 16. 服务器包

服务器包把**一个实例 + 启动器配置**打成一个 zip，适合服主一次性发给玩家：玩家拖进启动器后自动
导入并重启到该实例。

### 16.1 导出

设置 → 客户端设置 → 服务器包 → 「导出服务器包」，打开服务器包窗口。

1. 选择实例。
2. 可选「附带启动器 exe」；只有 Windows 支持，且导入时不会替换玩家当前的启动器程序。
3. 选择保存位置，导出 zip。

包内包含实例目录、`game.json`、启动器配置（`config.json` / `gui_config.json`）、清单
`mml-server.json`；附带 exe 时多一个 `MML.exe`。

### 16.2 导入

- 把 zip 拖到主窗口，或通过支持的链接启动；启动器会先校验清单、路径和条目。
- 导入会**强制覆盖同名配置**并重启启动器；请先停止游戏、等待启动任务结束，并备份自己的配置。
- 包内附带的 exe 只用于便携启动，不会替换当前安装的程序。

## 17. 数据与备份

运行目录默认在 Windows 是程序同级的 `mml/`，安装版可能由数据目录里的 `run` 文件指定；
Linux 是 `~/.mml/`，macOS 是 `/Users/shared/mml/`。主要目录：

| 路径 | 内容 |
| --- | --- |
| `minecraft/` | 版本、运行库、资源与全部实例（`instances/<名字>/`） |
| `java/` | 下载的 Java 运行时 |
| `cache/` | 下载缓存与 WebView2 数据 |
| `logs.log` | 启动器运行日志 |
| `gui_config.json` | 界面、主题、窗口模式、客户端设置、登录 / 实例锁定 |
| `config.json` | 下载源、线程、代理、DNS、检查与 SHA1 开关、游戏启动默认参数 |
| `window_save.json` | 窗口位置、大小、最大化 |
| `collect.json` | 资源收藏与分组 |
| `group_save.json` | 实例分组 |
| `count.dat` | 游戏统计 |
| `custom_ui/` | 样式包与主题包 |

实例目录 `minecraft/instances/<名字>/` 里主要是：`game.json`（实例设置）、`gui_setting.json`
（模组分组 / 资源窗口 / 日志设置）、`.minecraft/`（游戏目录）、`backup/`（存档备份）、`mods/`、
`modfileinfo.json`、`icon.png`。

**备份**：直接复制整个运行目录即可。实例也可以单独导出成整合包；存档在资源管理里有备份 / 还原。

## 19. 已知限制

以下是当前版本确实存在、会影响使用的限制：

1. **未登录微软正版账户时不能启动离线账户**：本机至少成功登录过一个微软账户后，离线账户才可用；
   只添加皮肤站 / 外置登录 / 统一通行证不算正版登录记录。前端会禁用启动按钮，后端命令也会拒绝。
2. **映射大厅未接入**：页签和搜索框已经就绪，后端服务还没接，创建 / 加入会提示未接入。
3. **URI 启动 / 沙盒启动未实现**：设置里的开关只保存选择；管理员启动是可用功能。
4. **资源包启用 / 禁用可能不生效**：启动器目前可能写错配置文件，原版实例还可能报错；
   建议在游戏内「选项 → 资源包」切换。
5. **实例的「游戏内语言」暂不生效**：选择会保存，但启动时还没有写进游戏参数。
6. **下载只有全局控制**：不能单独暂停某个任务；添加资源任务也不能取消。
7. **服务器包导入会覆盖配置**：导入前请停止游戏并备份自己的 `config.json` / `gui_config.json`。
8. **联机大厅要求微软正版账户**：部分系统或处理器不支持陶瓦联机；大厅打开期间账户被锁定。

如果这些问题已经影响使用，请先按[帮助与反馈](#18-帮助与反馈)附日志反馈。
